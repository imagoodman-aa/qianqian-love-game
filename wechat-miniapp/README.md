# 芊芊的快乐补给站 · 微信小程序

这是网页项目的原生微信小程序版本。四个游戏使用独立页面，留言仍通过现有 Supabase 服务保存，因此网页和小程序看到的是同一份留言。

## 第一次导入

1. 微信开发者工具选择“导入项目”。
2. 项目目录选择本文件所在的 `wechat-miniapp` 文件夹。
3. AppID 已写入 `project.config.json`。
4. 在开发者工具顶部点击“云开发”，创建一个免费体验环境。
5. 在 `cloudfunctions/loveProxy` 上右键，选择“上传并部署：云端安装依赖”。
6. 编译后，用 James 或 Franca 登录测试。

## 只给两个人使用

不要提交正式发布。上传代码后，在微信公众平台把当前开发版本设为体验版，并只添加女朋友为体验成员。管理员本人默认可以体验。

## 安全说明

- 小程序代码中没有两个账号的密码，也没有 Supabase 服务密钥。
- 小程序只把登录内容发送给自己的微信云函数，云函数再连接现有受保护接口。
- 图片先临时上传到微信云存储，转存到原来的私有图片桶后立即删除临时文件。
- 不需要填写或分享微信 AppSecret。
